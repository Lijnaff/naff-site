Implemented captive portal with voucher security and a Proxmox/Docker local server for automated HD security backups.

Data Scripting Brand Design pfSense OpenWrt 5G Dual-Carrier Captive Portal Proxmox Docker CapCut 4K Photoshop Illustrator

Problem

Harme Cafe was running on manual spreadsheets for sales tracking, inventory management, and financial reporting. Daily reconciliation took 2-3 hours, errors were frequent, and there was no real-time visibility into stock levels or revenue trends.

Solution

Result

Reduced daily reporting time from 3 hours to under 15 minutes. Zero stock-out incidents since automation went live. Network uptime improved to 99.9% with dual-carrier failover. Brand recognition increased significantly with professional visual assets.

Project Glitch — AI Architect & Developer

April 2026 – Present

Architected and deployed "Glitch," a localized, high-speed personal AI assistant built on the OpenClaw platform. Designed an entirely on-premise execution environment ensuring absolute data privacy, zero external API costs, and low-latency responses. Applied specialized RLHF training logic to optimize contextual understanding, transforming complex technical documentation into a conversational productivity tool.

OpenClaw AI Agent RLHF On-Premise Data Privacy Local LLM Python

Problem

Needed a personal AI assistant for technical documentation, project management, and daily productivity — but cloud-based solutions raised data privacy concerns and recurring API costs. Existing local solutions were either too complex to set up or lacked the conversational quality needed for productive use.

Solution

Built Glitch on the OpenClaw platform with a fully on-premise architecture. Implemented custom RLHF (Reinforcement Learning from Human Feedback) training to optimize the model's understanding of my specific technical context and communication style. Created a web-based dashboard for chat, model management, training jobs, and document management — all running locally with zero external API dependencies.

Result

Sub-second response times for most queries. Complete data privacy with zero API costs. The RLHF training improved response relevance by ~40% compared to the base model. Now serves as the primary tool for technical research, documentation parsing, and daily productivity.

0$ API costs, full privacy
